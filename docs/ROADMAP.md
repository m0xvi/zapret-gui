## 4. Подбор и автоконструктор стратегии — новый крупный блок

### Важное ограничение

Локальная DPI-проверка не может достоверно определить ISP пользователя по названиям
провайдеров тестовых endpoint-ов. Поэтому приложение не должно автоматически заявлять:
«ваш провайдер — X», если это не подтверждено отдельным источником.

Будут поддерживаться три источника контекста:

- `[x]` провайдер, введённый пользователем вручную (с отображением источника);
- `[x]` ASN/провайдер, полученный через отдельный явно разрешённый пользователем внешний
      сервис, с отображением источника и времени проверки;
- `[x]` профиль, построенный только по результатам тестов этого компьютера — без названия
      ISP и с низкой/средней уверенностью; используется только для приоритета кандидатов.

Названия провайдеров в `suite.v2.json` остаются только названиями инфраструктуры
тестовых endpoint-ов и не используются как доказательство ISP пользователя.
