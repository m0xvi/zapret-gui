Скопируйте текст ниже целиком и отправьте его в новую сессию (агенту, который продолжит работу).
В квадратных скобках — то, что нужно дописать вам.

---

Ты продолжаешь разработку проекта **Zapret GUI** — графического интерфейса для сборки
`Flowseal/zapret-discord-youtube` (Windows, C# .NET 8 + WPF, MVVM).

**Сначала прочитай в репозитории (в этом порядке):**
1. `AGENTS.md` — правила проекта, контракты, что нельзя ломать, как добавлять страницы.
2. `docs/HANDOFF.md` — полный контекст: что реализовано, карта кода, факты о движке zapret,
   что проверено и что НЕ проверено, список подводных камней, бэклог и журнал работы.
3. `README.md` — пользовательское описание и команды сборки.

**Рабочий цикл (важно):** ты НЕ пушишь в GitHub. Ты пишешь код в своей песочнице, проверяешь
его тремя проверками из `AGENTS.md` §3 (`dotnet build` без предупреждений,
`python3 tools/check_bindings.py`, `dotnet run -p tools/StrategyParserHarness "/путь/к/движку"`),
упаковываешь исходники в zip и отдаёшь мне файл — я сам загружу его в репозиторий, откуда
GitHub Actions соберёт exe. Всё общение и весь код — на русском.
