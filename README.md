# Zapret GUI

Графический интерфейс (Windows, .NET 8 + WPF) для популярной сборки
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) —
удобная замена `general*.bat` и `service.bat`.

Приложение **не содержит** бинарников zapret и **не изменяет** вашу сборку:
оно читает .bat-файлы стратегий и запускает `bin\winws.exe` с точно теми же
аргументами, что и оригинальные скрипты.

---

## Возможности (v1.0.0)

### Управление обходом
- Запуск и остановка обхода одной кнопкой; индикатор состояния, время работы, PID.
- **Список стратегий формируется автоматически** из .bat-файлов движка: новые
  стратегии из официальных релизов появляются в интерфейсе без обновления GUI.
- Человекочитаемое описание каждой стратегии (fake TLS + SNI, multisplit, повторы,
  fooling, режим «все протоколы» и т. п.) и полный список аргументов winws.exe.
- Установка выбранной стратегии в **службу Windows** `zapret` (автозапуск при
  включении ПК) и полное удаление служб `zapret` / `WinDivert` / `WinDivert14`.
- Игровой фильтр (выкл / TCP+UDP / только TCP / только UDP) — как Game Filter в `service.bat`.
- Режимы ipset `loaded` / `none` / `any` с автоматическим управлением `ipset-all.txt.backup`.
- Флаг `utils\check_updates.enabled` для запуска через .bat-файлы.

### Обновления из официального репозитория
- Проверка последнего релиза через GitHub API (и резервно — через `.service/version.txt`).
- **Автоматическая загрузка и распаковка** движка прямо в GUI с прогресс-баром;
  поддержка `.zip` и `.tar.gz` ассетов релиза, канал release / pre-release.
- Умное обновление: сохраняются `*-user.txt`, режимы ipset и игрового фильтра,
  активные фейки; перед изменением ничего не затирается молча.
- Если обход работал — он автоматически перезапускается с новой версией.
- Отдельные действия: обновление `lists\ipset-all.txt`, проверка и **безопасное
  применение `hosts`** (с резервной копией и маркерами блока, без ручного копирования).
- Автопроверка обновлений при запуске приложения.

### Диагностика (аналог Run Diagnostics)
Проверяются: права администратора, наличие `winws.exe`/`WinDivert64.sys`, кириллица
в пути, OneDrive, служба BFE, TCP timestamps, системный прокси, активные VPN-адаптеры,
конфликтующие службы (Adguard, Killer, Intel Connectivity, Check Point, SmartByte),
посторонние обходы и «чужие» winws.exe, остаточные службы WinDivert, состояние службы
zapret, файл hosts, размер кэша Discord. Есть исправления в один клик: удалить службы,
включить timestamps, очистить кэш Discord, сбросить сеть (`winsock`, `ip`, `winhttp`, `flushdns`).

### Интерфейс
- Тёмная, светлая тема и режим «как в системе» (переключается на лету).
- Сворачивание в трей с быстрыми действиями «запустить/остановить обход».
- Проверка соединения (YouTube, Discord, GitHub) одной кнопкой.
- Живой журнал всех действий и вывода утилит, с фильтрами по уровням и сохранением в файл.
- Автозапуск приложения при входе в систему (планировщик задач, права администратора).
- Настройки хранятся в `%APPDATA%\ZapretGUI\settings.json`, журнал — в `...\logs`.

## Сборка

### Автоматически (GitHub Actions) — рекомендуемый способ

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки:
   ```bash
   git init
   git add .
   git commit -m "Zapret GUI 1.0.0"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/zapret-gui.git
   git push -u origin main
   ```
2. Действие `Build and Release` запустится само. Результат — вкладка **Actions** →
   артефакты (`ZapretGUI-<версия>`): портативный EXE и zip для .NET 8.
3. Чтобы получить полноценный релиз с файлами для скачивания, создайте тег:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   Workflow соберёт приложение и создаст Release с двумя файлами.

### Локально (Windows)

```powershell
dotnet publish src/ZapretGUI/ZapretGUI.csproj -c Release -r win-x64 `
  --self-contained true -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Готовый файл: `publish\ZapretGUI.exe`. Проект также собирается на Linux/macOS
(в csproj включён `EnableWindowsTargeting`) — это нужно для CI, но запускать
Windows-приложение там нельзя.

## Технические решения

- **Парсинг стратегий вместо хардкода.** GUI читает те же .bat-файлы, что и
  оригинальные скрипты (строка с `winws.exe`, продолжения через `^`, подстановка
  `%BIN%`/`%LISTS%`/`%GameFilterTCP%`). Поэтому новые стратегии и изменения
  аргументов в релизах подхватываются автоматически.
- **Прямой запуск процесса** с `ArgumentList` вместо `cmd.exe /c` — не нужны
  трюки с экранированием `^!` и кавычками.
- **Права администратора** запрашиваются через манифест (`requireAdministrator`),
  нужны для WinDivert, служб и правки `hosts`.

## Планы (следующая итерация)

- Автотест стратегий (порт `utils\test zapret.ps1`) с оценкой по каждому сайту из `targets.txt`.
- Визуальный конструктор стратегий (редактор аргументов winws с подсказками).
- Профили: разные стратегии для разных сетей/провайдеров.
- Расписание: обход по таймеру, автопереключение при падении доступности.
- Настройка DoH (DNS-over-HTTPS) из приложения, проверка DNS-подмены.
- Импорт/экспорт списков, редактор списков прямо в GUI с подсветкой.
- Обновление самого GUI из собственного репозитория.
- Локализация (EN) и настройка акцентного цвета.
